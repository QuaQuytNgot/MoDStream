# MoDGStream

Visibility-Aware Adaptive Streaming for Multi-Object Dynamic 3D Gaussian Splatting.

This repository currently contains only the research project website. Framework source code is reserved for a later release.

In GitHub Settings → Pages, choose **GitHub Actions** as the source. Push the main branch or run **Publish research project page** manually. Only docs/ is deployed.

Recordings are prerecorded visualizations; the adaptation playback comparison is proposed. Unconfirmed paper, code, author, venue, and citation fields remain blank or disabled.
